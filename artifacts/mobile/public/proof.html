GLSL VERTEX SHADER BUG — JavaScript Simulation (no WebGL required)

The Three.js vertex shader had: pow(position.x / 1.1, 2.0)
In GLSL ES 1.0, pow(x,y) is UNDEFINED when x < 0. The plane is 2.2 units wide, so position.x ∈ [−1.1, +1.1].
Any vertex with position.x < 0 (the entire LEFT HALF of the plane) triggers undefined behavior.
On many mobile GPUs, pow(negative, 2.0) returns NaN → the vertex position becomes NaN → triangle is clipped → dark area.
